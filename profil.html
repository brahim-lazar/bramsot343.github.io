BTS SIO

Formation BTS SIO

Le BTS SIO se décline en deux spécialités. Ma formation SISR m'a permis d'aborder également des notions SLAM, assurant une vision complète du domaine.

🖧
SISR
Solutions d'Infrastructure, Systèmes et Réseaux
Ma spécialité
  • Administration systèmes : Windows Server & Linux (Debian, Ubuntu), gestion des utilisateurs, droits, services systemd.
  • Réseaux & routage : Adressage IP, VLANs, protocoles RIP / OSPF, configuration de routeurs et commutateurs.
  • Virtualisation : VMware ESXi, VirtualBox, Proxmox — création et gestion de machines virtuelles.
  • Sécurité réseau : Pare-feux pfSense, règles ACL, VPN OpenVPN / IPsec, politiques de sécurité.
  • Services réseau : DHCP, DNS, Active Directory, Apache, Nginx, SSH, FTP.
  • Supervision : Monitoring avec Zabbix et Nagios, analyse des logs système.
💻
SLAM
Solutions Logicielles et Applications Métiers
Notions abordées
  • Développement web : HTML, CSS, initiation JavaScript pour des interfaces simples.
  • Bases de données : Modèles relationnels (MCD/MLD), requêtes SQL (SELECT, JOIN, UPDATE).
  • Scripting : Bash sous Linux et PowerShell sous Windows pour l'automatisation de tâches.
  • Algorithmique : Structures de base : boucles, conditions, fonctions, tableaux.
  • Applications réseau : Manipulation d'APIs, sockets et protocoles HTTP dans le cadre des projets SISR.
